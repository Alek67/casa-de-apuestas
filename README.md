# VortexBet - Casa de Apuestas Deportivas

Plataforma web demostrativa e interactiva de apuestas deportivas, diseñada **100% sin imágenes externas**, construida con HTML5, CSS3 moderno y JavaScript vanilla.

## Características

- **Diseño Dark Theme**: Aspecto deportivo profesional utilizando únicamente degradados CSS, micro-interacciones y badges SVG/tipográficos.
- **Sin Imágenes**: Máxima velocidad de carga y rendimiento sin dependencias de activos multimedia externos.
- **Boleto de Apuestas Interactivo**:
  - Modalidad de apuestas simples y combinadas (*parlay* con multiplicación de cuotas).
  - Cálculo automático de ganancia potencial en tiempo real.
  - Selección de importe mediante chips rápidos (+5, +10, +50, Máx).
- **Mis Apuestas y Cashout**: Historial de apuestas en juego con función de cobro anticipado.
- **Cuotas Dinámicas**: Simulación de oscilación de cuotas en vivo con efectos visuales.
- **Recarga de Saldo Ficticio**: Modal integrado para simular depósitos instantáneos.
- **Filtros**: Navegación por deportes (Fútbol, Baloncesto, Tenis, eSports, MMA), ligas y buscador en vivo.

## Instalación y Uso

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Alek67/casa-de-apuestas.git
   cd casa-de-apuestas
   ```

2. Abre `index.html` directamente en tu navegador o inicia el servidor local de prueba:
   ```bash
   node server.js
   ```
   Luego ingresa a `http://localhost:3000`.
